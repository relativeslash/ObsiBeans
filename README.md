# ObsiBeans

An Obsidian plugin project for managing Beans through a native, ALM-style workspace. The workspace design is accepted for v1. A desktop plugin skeleton with quality gates exists; v1 features are not implemented yet.

- [Documentation](docs/README.md) — design and workflow navigation.
- [Contributing](docs/Private/Contributing/README.md) — inherited Protomatter standards and optional project overrides.
- [Project information](docs/Private/Contributing/ObsiBeans%20project%20info.md) — compatibility baseline, toolchain and development commands.
- [AI working guide](docs/Private/Guides/ObsiBeans%20AI%20working%20guide.md) — skills and development guidance.
- [V1 implementation plan](docs/Private/Tasks/OB-fgjv--obsibeans-v1-native-workspace.md) — dependency-ordered Beans backlog and agent starting points.

The repository root is the `ObsiBeans` Obsidian vault. `docs/` is its documentation subtree, not a separate vault. Global standards are referenced, not copied into local standards notes.
