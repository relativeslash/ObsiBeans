## Boundaries

`Private/` holds development guidance, proposals and work records; it is not approved for publication. `Public/` is reserved for explicitly approved public documentation. Proposed designs describe intended behavior, not shipped capabilities. Work status belongs in Beans under the configured task directory.

Global Protomatter standards apply by default. Local standards notes contain only actual project differences; missing or empty optional override notes are not missing global guidance. The AI working guide lives under `Private/Guides/`, not at the vault root.
